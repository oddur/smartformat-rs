# smartformat-rs

[![CI](https://github.com/oddur/smartformat-rs/actions/workflows/ci.yml/badge.svg)](https://github.com/oddur/smartformat-rs/actions/workflows/ci.yml)

A Rust port of [SmartFormat.NET](https://github.com/axuno/SmartFormat) —
string templating with named placeholders, pluralization, conditional
formatting, and list formatting.

```text
{Name} has {Count} {Count:plural:item|items} in {Gender:choose(m|f):his|her} cart
```

The goal is **compatibility**: templates written for the .NET library render
identically here, including .NET standard format specifiers (`{0:N2}`,
`{Date:d}`, …). Compatibility is verified against golden outputs generated by
the real C# library.

**Status: early work in progress.** Nothing renders yet. See
[DESIGN.md](DESIGN.md) for scope, decisions, and milestones.

## Planned shape

```rust
use smartformat::{SmartFormatter, ToSmartValue};

#[derive(ToSmartValue)]
struct Cart { name: String, count: i64 }

let sf = SmartFormatter::default();
let out = sf.format("{name} has {count} {count:plural:item|items}", &cart)?;
```

## Crates

- `smartformat` — parser, formatter, built-in extensions (feature-gated,
  default-on: `plural`, `time`, `regex-formatters`)
- `smartformat-derive` — `#[derive(ToSmartValue)]`
